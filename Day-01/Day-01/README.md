# Day 01 - Two Sum

## Problem Statement
Given an array of integers and a target value, return the indices of two numbers whose sum equals the target.

## Approach
1. Iterate through the array using a loop.
2. Use a second loop to check the remaining numbers.
3. Check whether the sum of the two numbers equals the target.
4. Return their indices when the sum matches the target.

## Example

Input
- nums = [2, 7, 11, 15]
- target = 9

*Output
- [0, 1]

Explanation

The numbers 2 and 7 add up to 9. Their indices are 0 and 1.

## Complexity Analysis
- Time Complexity: O(n²)
- Auxiliary Space Complexity: O(1)

## Language
Python
